## 👨‍💻 About me

I'm a **Backend Developer** focused on building robust, scalable, and well-documented applications. I work mainly with **TypeScript, Node.js, NestJS, PostgreSQL, and Docker**, creating REST APIs and applying clean-code practices.

My background also includes front-end and mobile development, IT infrastructure, technical leadership, and mentoring developers. I enjoy sharing knowledge and turning complex challenges into efficient software solutions.

- 💼 Backend Mentor at **SouJunior**
- 📍 Based in Cachoeira do Sul, Rio Grande do Sul, Brazil
- 🧩 Experienced with REST APIs, MVC, OOP, TDD, SOLID, Scrum, and Kanban
- 🤝 Open to collaborating on meaningful projects and learning new technologies

## 🚀 Professional highlights

- Mentor teams in the planning, development, testing, and documentation of REST APIs using **Node.js and NestJS**.
- Build backend solutions with **TypeScript, PostgreSQL, Docker, Git, TDD, and SOLID principles**.
- Former **IT Technical Manager at the Brazilian Army**, working with servers, networks, virtualization, intranets, and team leadership.
- Experience developing web and mobile applications with **React, React Native, JavaScript, and TypeScript**.
